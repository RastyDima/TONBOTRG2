# Бонусы, напоминания и история

- «Бонусы» в главном меню или `/bonuses` показывает оба бонуса, суммы и даты обновления.
- `/daily` и `/weekly`, включая кнопки в старых сообщениях, получают соответствующий бонус и открывают общий экран.
- `/reminders` позволяет независимо включать ежедневные и еженедельные напоминания. Настройки сохраняются между перезапусками; получение бонусов остаётся доступным при отключённых напоминаниях.
- `/history` показывает по 10 операций с фильтрами «Все», «Игры», «Бонусы», «Переводы», «Магазин» и «Рефералы». «Обновить» загружает новые операции. Переключение страниц сохраняет исходный список и выбранный фильтр.

Даты обновления используют время сервера, как и начисление бонусов. Текущие настройки напоминаний по умолчанию сохраняются: оба типа включены. Миграции SQLite и PostgreSQL выполняются через `init_db()` без сброса пользовательских данных.

Проверки: `python -m unittest discover -s tests -v`. Для интеграционных проверок PostgreSQL задайте `TEST_POSTGRES_URL` к отдельной тестовой базе. GitHub Actions запускает полный набор с PostgreSQL 16.
